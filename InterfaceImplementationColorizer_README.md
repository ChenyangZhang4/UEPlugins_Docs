# Interface Implementation Colorizer

**Interface Implementation Colorizer** is an editor-only Unreal Engine plugin that colors Blueprint Interface members in **My Blueprint > Interfaces** according to their implementation state.

It makes it possible to see which interface events and functions are unimplemented, empty, or implemented without opening each graph individually.

**Supported Unreal Engine version:** UE 5.8

## Features

### Interface Implementation States

Interface members are displayed using three configurable visual states:

- **Unimplemented** — default gray
- **Empty** — default amber
- **Implemented** — default green

The colors can be changed in:

```text
Editor Preferences
  -> Plugins
  -> Interface Implementation Colorizer
```

The plugin only changes the editor presentation of interface members. It does not modify Blueprint asset data or runtime behavior.

## Interface Event Classification

Blueprint Interface events are classified according to whether the event exists and whether its execution output is connected.

Default rules:

| Situation | Default State |
| --- | --- |
| Interface Event is not placed in an Event Graph | Unimplemented |
| Interface Event exists but execution is not connected | Empty |
| Interface Event exists and execution is connected | Implemented |

Each situation can be independently mapped to **Unimplemented**, **Empty**, or **Implemented** in Editor Preferences.

## Interface Function Classification

Interface functions are evaluated using the contents of their implementation graph.

Default rules:

| Situation | Default State |
| --- | --- |
| Function execution pin is disconnected | Unimplemented |
| Only the autogenerated `Entry -> Return` stub exists and Return values remain at autogenerated defaults | Unimplemented |
| No authored nodes exist, but a Return default value was manually changed | Empty |
| Pure/data-flow nodes are used to calculate outputs | Implemented |
| Executable logic nodes exist | Implemented |

Comments are ignored when determining whether implementation logic has been authored.

### Classification Priority

A function always resolves to one classification using this fixed priority:

1. Execution pin is disconnected
2. Executable logic nodes exist
3. Pure/data-flow nodes exist
4. Return default value was manually changed
5. Only the autogenerated default stub remains

This ordering avoids ambiguous results when a graph satisfies more than one condition.

### Autogenerated Entry to Return Stub

A newly implemented output-bearing Blueprint Interface function commonly starts as:

```text
Entry -> Return
```

This alone is not considered authored implementation logic.

If the graph contains no authored nodes and all Return data pins still match their Unreal-generated default values, the function uses the **Only Autogenerated Entry To Return Exists** rule.

If a Return default value is manually changed while no authored graph nodes exist, the function instead uses the **Return Default Value Was Manually Changed** rule.

### Pure/Data-Flow Logic

A function is considered to contain pure/data-flow logic when authored nodes without execution pins are used in the graph.

This allows pure interface implementations that calculate output values without executable nodes to be recognized as implemented.

### Executable Logic

If at least one authored node with an execution pin exists, the function uses the **Executable Logic Nodes Exist** rule.

This rule has priority over the pure-node rule.

## Settings

Open:

```text
Editor Preferences
  -> Plugins
  -> Interface Implementation Colorizer
```

### Colors

**Unimplemented Color**  
Color used for interface members classified as Unimplemented.

Default:

```text
Gray
```

**Empty Color**  
Color used for interface members classified as Empty.

Default:

```text
Amber
```

**Implemented Color**  
Color used for interface members classified as Implemented.

Default:

```text
Green
```

### Event Classification Rules

Each of the following settings can be assigned to **Unimplemented**, **Empty**, or **Implemented**:

- **Event Is Not Placed**
- **Event Exists But Execution Is Not Connected**
- **Event Execution Is Connected**

### Function Classification Rules

Each of the following settings can be assigned to **Unimplemented**, **Empty**, or **Implemented**:

- **Function Execution Pin Is Disconnected**
- **Only Autogenerated Entry To Return Exists**
- **Return Default Value Was Manually Changed**
- **Pure Nodes Are Used To Calculate Outputs**
- **Executable Logic Nodes Exist**

### Behavior

**Refresh Interval**  
Controls how often visible **My Blueprint** panels are rescanned and recolored.

Default:

```text
0.20 seconds
```

The setting can be adjusted from `0.05` to `2.0` seconds.

**Include Inherited Interfaces**  
Controls whether Blueprint Interfaces inherited from parent Blueprints/classes are also included.

Enabled by default.

## Usage

Once the plugin is enabled, no additional workflow is required.

1. Open a Blueprint that implements one or more Blueprint Interfaces.
2. Find the **Interfaces** section in the **My Blueprint** panel.
3. Interface functions and events are automatically classified.
4. Their displayed text is recolored using the configured state colors.
5. Edit the interface graph/event normally; the visible state is refreshed automatically.

For example:

```text
Interfaces

BPI_Interact
  Interact               Green
  CanInteract            Amber
  OnInteractionCancelled Gray
```

The exact meaning of each color depends on the classification rules configured in Editor Preferences.

## Inherited Interfaces

When **Include Inherited Interfaces** is enabled, the plugin also evaluates interface members inherited through parent Blueprint/classes.

Disable this option if you only want to color interfaces directly implemented by the current Blueprint.

## Installation

1. Copy the `InterfaceImplementationColorizer` folder into your project's Plugins directory:

```text
YourProject/
  Plugins/
    InterfaceImplementationColorizer/
```

2. Regenerate project files if required.
3. Build the Editor target.
4. Start Unreal Editor and enable **Interface Implementation Colorizer** if it is not already enabled.
5. Restart the editor if requested.

The plugin contains an **Editor-only** module and does not add runtime logic to packaged builds.

## Design Scope

Interface Implementation Colorizer is intentionally focused on improving the readability of Blueprint Interface implementation state inside the editor.

It:

- Reads existing Blueprint Interface functions and events.
- Classifies them using configurable editor rules.
- Colors the corresponding members in **My Blueprint > Interfaces**.
- Does not modify Blueprint graphs.
- Does not modify interface definitions.
- Does not add runtime code or behavior to the game.
